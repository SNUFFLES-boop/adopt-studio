Sign in with your GitHub key

This page saves changes straight to your GitHub repository, so it needs a private key that only you have. You make it once.

  1. Open GitHub → New fine-grained token.
  2. Name it Adopt-Studio shop and pick an expiration.
  3. Under Repository access choose Only select repositories → adopt-studio.
  4. Under Permissions → Repository permissions set Contents to Read and write (and Pages to Read-only if you see it).
  5. Click Generate token, copy it and paste it below.

Never share this key or paste it anywhere else. Anyone with it can change your shop. You can delete it any time on GitHub.
